# 0005 · 复习调度：FSRS（ts-fsrs）

- 状态：已采纳
- 日期：2026-10-24

## 背景

间隔重复是整套方法里证据最强的一部分（Cepeda 等 2006 年的综合分析）。需要一个调度算法，决定每张卡片什么时候再复习。

## 选项

1. SM-2（老版 Anki 的算法）
2. 固定间隔表（1、3、7、14、30 天）
3. **FSRS**（Anki 现在的默认算法），用 ts-fsrs 实现

## 决定

选 3，ts-fsrs 5.4.2。参数：目标记忆保持率 0.9、最长间隔 180 天、关闭当天内的学习步骤（`enable_short_term: false`）、开启间隔随机化（fuzz）。

## 原因

- FSRS 根据每张卡片的实际表现估算记忆稳定性，比 SM-2 和固定间隔更省复习次数。
- ts-fsrs 是纯 TypeScript、MIT 许可、无原生依赖，可以在共享代码里直接测试。
- 只用三个评分（忘了 / 有点难 / 会了），更多情况下由题目自动评分（选择题、语音比对），她不用纠结选哪个按钮。
- 当天内重新学习由课程流程负责，所以调度器只管"按天"的间隔。

## 后果

- 第一次学完一句话，按"有点难"处理，所以第二天就会出现在复习里（`introduceCard`）。
- 算法细节封装在 `src/shared/domain/srs.ts` 的 `StoredCard` 里，数据库不依赖 ts-fsrs 的类型；以后换算法只改这一个文件。
- 每天复习有上限（默认 20 张），超出的自动顺延，不会显示成"欠账"。
