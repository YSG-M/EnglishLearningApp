# 0006 · 句型 + 场景结合的课程，重上课程，复习分"最近"和"全部"

- 状态：已采纳（2026-10-24 用户确认）
- 日期：2026-10-24

## 背景

学习者实际使用后的反馈（由用户转达）：

1. **不敢说、不知道怎么表达。** 心里有意思，但组织不成英文句子。
2. 她喜欢抖音博主"学英语的老灯"（yiyantianya3）的教法：**一个句型配很多例句**（比如 `What did you buy / find / remember / dream about`），每句话都在一个对应的情景里学会。
3. 希望**每个词都能看到中文意思**。
4. 现有的自动播放、慢速、点单词发音、谐音、录音反馈都保留。
5. 上完的课**没办法再上一次**；课程页能看到上过的课，但打开后的内容和"今天"页里上课的样子不一样，希望统一。
6. 复习页：**所有上过的内容都要能复习**，分成"最近学的"和"全部学过的"两部分。

## 选项

| 选项                   | 说明                                                                                                              | 问题                                                                   |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| A. 只按场景（现状）    | 每单元一个场景，9 句不同的话                                                                                      | 句子之间没有共同的"框"，学了 9 句只会说这 9 句，换个场景就不知道怎么说 |
| B. 只按句型            | 一课一个句型，例句来自各种场景                                                                                    | 缺少一个完整场景里的连续对话，学了句型但不知道一件事怎么从头说到尾     |
| **C. 句型 + 场景结合** | 每个场景单元带 1–2 个万用句型；句型课的例句一半来自本单元场景，一半来自她的其他生活场景；后面单元反复用前面的句型 | 内容工作量大（见"后果"）                                               |

## 决定

选 **C**。

### 1. 课程结构（每单元仍是 3 天，节奏不变）

| 天      | 部分                                        | 内容                                                                        |
| ------- | ------------------------------------------- | --------------------------------------------------------------------------- |
| 第 1 天 | 📖 学新句子（`learn`）                      | 本单元场景的整句（现有内容）。用到本单元句型的句子标出"🔑 这就是明天的句型" |
| 第 2 天 | 🔑 **句型课**（原"句型和发音"，`practice`） | 见下面第 2 节；最后照旧接 3 分钟拼读                                        |
| 第 3 天 | 💬 实战对话（`apply`）                      | 现有分支对话；保证她的回答里有几句要用本单元句型，再加今日实战任务          |
| 第 7 天 | 🔁 本周复习                                 | 不变                                                                        |

每周 2 个单元、第 1 阶段 13 周 26 个单元，都不变。

### 2. 一节句型课（目标 20–25 分钟）

1. **认识句型**（约 1 分钟）：句型框（如 `Can you ___?`）、一句大白话讲什么时候用、"框里能放什么"。不用语法术语。
2. **例句**（每个句型 **10 句**，每句都有自己的场景；一个单元两个句型时合计 10–12 句）：每句一步，顺序是
   - 🎬 **场景**：一行中文，"在哪、对谁、要干什么"。例：_家长在前台说得太快，你没听清。_
   - 自动播放原音 → 句子（谐音 + 每个词的意思）→ 跟读录音 → 反馈（全部沿用现有 `SentenceCard` 的做法）
   - 句型部分高亮，变化的部分用另一种颜色，让她一眼看出"框不变，只换这里"
3. **看场景，自己说**（关键一步）：例句打乱顺序，只给场景和中文，她自己说英文。说不出来可以用三级提示（同现在复习里的"看中文说英文"）。
4. **拼读**：现有的拼读规则 + 听辨题（第 2 周开始，不变）。

例句的场景大约一半来自本单元（如前台），一半来自她的其他生活（hawker centre、诊所、家里、同事）；**不用旅游、国外酒店这类她用不到的场景**。

### 4. 每个词的意思

- 词库已经覆盖所有句子里的每一个词（核对过：411 个词，0 个缺），但现在的中文意思只在少数情况下显示（有口型说明的词、红色词，或者鼠标悬停）。
- 改为：**点任何一个词：播放读音 + 显示中文意思**（有口型说明的再加口型说明）。
- 另外在句子下面加一个"📖 逐词意思"开关，打开后每个词下面都显示中文意思。默认关闭，避免一次显示太多字分散注意力。
- 有些词在短语里意思不一样（`take a seat` 的 take 不是"拿"）。例句可以写一个可选的**短语说明**（如 "take a seat = 坐下"），点词时一起显示。

### 5. 重上课程，课程页和今天页统一

现状（核对代码后的理解，请确认）：

- "今天"页只显示**下一节**课，上过的课在这里进不去。
- "课程"页每个单元有两个按钮："打开"进入的是真正的课；"🔁 练一练"进入的是**复习题**（选择题、看中文说英文）。你看到的"不一样"很可能是这个"练一练"。

改为：

- 课程页里每一节上过的课都显示 **"再上一次"**，打开的就是**和今天页完全一样的上课流程**（同一个组件）。
- 课程页的单元卡片做成和今天页一样的样子（标题、图标、第几周第几天）。
- 再上一次：不重复加复习卡片，不改复习安排；学习时长照常记录；完成页写"又练了一遍 👍"，而不是"学会了 0 张新卡片"。
- "练一练"从课程页移到复习页（见下一节），课程页只管"上课"。

### 6. 复习页：今天的复习 + 最近 + 全部

| 区域           | 内容                                                             | 会不会改变复习安排 |
| -------------- | ---------------------------------------------------------------- | ------------------ |
| **今天的复习** | 现有的 FSRS 到期卡片，每天上限 20 张（不变，研究证据最强的部分） | 会                 |
| **最近学的**   | 最近 7 天上过的课里的所有卡片（句子、句型例句、单词、听辨）      | 不会               |
| **全部学过的** | 按单元列出所有上过的课，可以选一个单元练，也可以"随机抽 20 张"   | 不会               |

"最近"和"全部"是额外练习，**不改变 FSRS 间隔**：自由练习如果也改间隔，一张卡今天被练三遍，算法会误以为她已经记得很牢，把下次复习推得太远。学习时长照常计入今天。

### 7. 复习里"看场景说句子"

句型例句成为新的复习卡片（`example`）。实现时没有新增题型：沿用"看中文说英文"（以及语音不可用时的"自己评分"），例句卡片在中文上面多显示 🎬 场景。新卡的前两次仍先用"听音选意思"，从容易的开始。

## 原因

- **句型 + 很多不同例句**：同一个框见到的不同填法越多，越会自己造新句子（构式学习：Bybee 2006 _From usage to grammar_；N. Ellis 2002 频率效应综述）。证据：中等，以描述性研究和实验室研究为主。
- **场景**：在什么情境里学的，在类似情境里最容易想起来（编码特异性，Tulving & Thomson 1973）。证据：中等偏强。
- **看场景自己说**：自己从记忆里提取比反复看和跟读记得牢得多（提取练习，Karpicke & Roediger 2008，_Science_）。证据：**强**。
- **先在安全环境里演过一遍**：重复同一个任务能提高流利度（Bygate 2001），并降低开口时的紧张（外语焦虑：Horwitz, Horwitz & Cope 1986）。证据：中等。
- 保留场景单元和 3 天节奏：已经做好的 26 个场景、对话和音频都能继续用，改动最小。

## 后果

### 内容工作量（最大的一块）

- 26 个单元 × 约 10–12 个句型例句 ≈ **约 280 个新句子**，每句都要写场景、中文、可能的短语说明。
- 新句子里的新词需要补进词库，并**人工写谐音**，估计 150–250 个新词。
- 第 3 天的对话要调整，保证用到本单元句型。
- 第 1 天的场景句子基本不动，只标出用到句型的句子。
- 新增约 300–550 段音频，用 Kokoro 生成，约 1–2 小时。
- 内容按单元分给 4 个内容子代理并行写（在 wmux 的可见标签里运行），主代理检查质量。所有新谐音都要列入"待真人试听"清单。

### 复习量

每个单元多出约 10 张句型例句卡片，加上原来约 9 句 + 12 个词，每周新卡从约 40 张增加到约 60 张。每天 20 张的上限不变，多出来的自动往后推，**不会显示欠账**。如果她觉得句型卡片太多，可以只给"看场景自己说"那一半例句建卡片（待定，先按全部建卡做）。

## 已确认（2026-10-24，用户）

1. 句型排课表不用换。
2. 每个句型 10 个不同的例句，每个例句都有自己的场景。
3. 场景先用一行中文描述，不配图。
4. 课程页和今天页统一，按第 5 节做。
