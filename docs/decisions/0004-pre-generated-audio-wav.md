# 0004 · 课程音频：开发时预先生成，存成 WAV

- 状态：已采纳
- 日期：2026-10-24

## 背景

每个句子、单词、对话台词、拼读例词都需要发音。可以在 app 运行时实时生成，也可以在开发时一次生成好。

## 选项

1. 运行时用 Kokoro 实时生成
2. **开发时预生成，打包进 app**
3. 预生成后压缩成 MP3 / Opus

## 决定

选 2：`npm run content:audio` 用 Kokoro 生成 16-bit PCM WAV（24 kHz 单声道），文件名是
`<声音>_<哈希>.wav`，哈希来自"声音 + 文本"。

## 原因

- 播放立刻开始，不占她电脑的 CPU；app 不需要带 330 MB 的 Kokoro 模型。
- 内容可以人工试听、检查，有问题就改句子重新生成。
- 用哈希命名：改了一句话只会重新生成那一句，旧文件用 `--prune` 清理。
- 不压缩是因为不想新增依赖（MP3 编码器）；Chromium 原生支持 WAV。

## 后果

- 三个月的内容大约 1500–2000 个音频，按平均 2 秒算，大约 150–200 MB。可以接受；以后如果太大，再加压缩步骤。
- 她自己输入的、课程里没有的句子不能用 Kokoro 朗读，只能用 `speechSynthesis` 兜底。
- 语速固定在 0.9（`TTS_SPEED`），改语速要 `--force` 全部重新生成；🐢 慢速按钮用播放速度实现，不需要另外生成。
