# 0007 · 单元汇总、每周汇总、小故事和日常用词

- 状态：已采纳（2026-10-24 用户确认；日常用词由 8 个改为 12 个）
- 日期：2026-10-24

## 背景

用户反馈：每节课学过的句子分散在很多步骤里，没有一页能看到全部。希望：

1. 每个单元（= 一节课，3 天）有一页**汇总**，看到这个单元的所有句子。
2. 汇总里有**小故事**，把这个单元学到的东西串起来用一遍。
3. 每周也有一页汇总和小故事，用这一周学到的东西。
4. 小故事要两种都有：一篇"Amy 的一天"（叙述为主），一篇小剧本（全是对话）。

## 决定

### 1. 单元汇总页（26 页）

| 区域                   | 内容                                  |
| ---------------------- | ------------------------------------- |
| 标题                   | 单元名、"学完以后你能……"              |
| 📖 句子                | 第 1 天的全部句子                     |
| 🔑 句型                | 句型框 + 10 个例句（带 🎬 场景）      |
| 💬 对话里你说的话      | 实战对话里她的所有回答（去重）        |
| 🔤 单词                | 这个单元的复习单词（意思 + 拼音）     |
| 📚 小故事 ① Amy 的一天 | 8–12 句，叙述为主，可以有一两句对话   |
| 🎭 小故事 ② 小剧本     | 8–14 句，全是对话，不同角色用不同声音 |

每一句都和课程里一样：拼音、点词看意思、▶ 播放、🐢 慢速。每个区域都有"▶ 全部播放"，可以从头听到尾。故事每一句还可以跟读录音。

### 2. 每周汇总页（13 页）

本周两个单元的句子和句型例句（按单元分开，可以折叠），再加两篇故事（同上，用这一周学到的东西）。

### 3. 从哪里进入

- 课程页：每个单元名旁边有"📄 汇总"，每周卡片上有"📄 本周汇总"。随时都能打开，不用先学完。
- 第 3 天"实战对话"完成后，完成页多一个按钮"看本单元汇总和小故事"。
- 第 7 天"本周复习"完成后，完成页多一个按钮"看本周汇总和小故事"。

### 4. 故事内容规则

- **只用学过的东西**：故事里每个词都必须在词库里（校验会报错）。另外校验会对"到这个单元为止还没在任何句子里出现过的词"给出警告，写的时候要把警告清零，确实需要的新词控制在每篇 2 个以内。
- 主角是 Amy（她自己），场景是她的生活：补习中心前台、家长、同事、hawker centre、HDB、MRT。不写旅游、出国。
- 大量直接复用本单元的原句和句型例句，再用前面单元的句子串起来，让她在新的情境里再听到、再说一遍。
- 每句都有自然的中文翻译。句子短，第 1 阶段每句最多 10 个词。
- 小剧本的角色用不同的 Kokoro 声音；Amy 用默认声音 `bf_emma`。
- 故事由内容子代理编写，主代理检查，最后由用户试读把关（和其他内容一样）。
- 故事**不建复习卡片**：复习卡片已经够多了，故事是"在新情境里再用一遍"，不算新内容。

### 6. 每个单元多一些日常用词和日常情景（2026-10-24 用户追加）

现状：工作单元和生活单元各占一半，但句型例句、对话的场景偏向补习中心（前台、家长、老师），生活场景不够多。

做法：

| 部分                  | 改动                                                                                                                                                                                                                                  |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 🏠 **日常用词**（新） | 每个单元加 12 个和本单元有关、但**用在生活里**的常用词，每个词配一句生活小句子和一行 🎬 场景。例：接电话单元加 `ring / busy / message / battery / charge…`，配 "My phone has no battery." 这类句子。放在第 1 天"学新句子"的单词表前面 |
| 🔑 句型例句           | 10 个例句里**至少 6 个是生活场景**（hawker centre、NTUC、MRT、HDB、诊所、家里、朋友、邻居），工作场景最多 4 个                                                                                                                        |
| 📚 / 🎭 小故事        | 两篇故事里至少一篇是生活场景（下班后、周末、家里、买东西、看病）                                                                                                                                                                      |

- 日常用词会建复习卡片（和现在的单词卡一样），每个单元多 12 张；每天复习上限不变，多出来的自动往后排。
- 第 1 天会长约 5–6 分钟（12 个词各听一遍、跟读一次）。

## 后果

- 新内容：39 页汇总不用写（自动从现有内容生成）；**78 篇小故事**要写（26 个单元 + 13 周，各 2 篇），约 800 句，需要生成约 800 段音频（约 10 分钟）。
- 新词：故事基本只用学过的词；日常用词每单元 12 个，共约 300 个新词（人工写谐音和拼音）、约 300 句生活小句子。
- 句型例句：工作场景超过 4 个的单元，要把多出来的换成生活场景（例句 id 不变，改内容）。
- 代码：内容格式和编译（故事、"学过的词"检查）、两个新页面、课程页入口、两个完成页按钮、全部播放（复用本周复习里已有的连续播放）。
- 4 个内容子代理按周分工并行写故事、日常用词、调整例句；主代理做代码。
