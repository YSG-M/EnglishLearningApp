# 0002 · 语音：sherpa-onnx（Kokoro 朗读 + Whisper 识别），全部离线

- 状态：已采纳
- 日期：2026-10-24

## 背景

硬性约束：**完全免费、离线优先**。需要两样能力：

1. 朗读（TTS）：每个句子、单词、对话都要有自然的英语发音；
2. 识别（ASR）：她跟读或者自己说的时候，判断说对了没有。

电脑是入门级游戏本（8–16 GB 内存、入门独显）。

## 选项

| 选项                                         | 问题                                                                          |
| -------------------------------------------- | ----------------------------------------------------------------------------- |
| Azure / Google 云语音                        | 要账号和信用卡，有费用，需要联网，录音会上传                                  |
| Windows 自带语音（SAPI / `speechSynthesis`） | 免费离线，但声音机械；Windows 自带的识别对中国口音的成人初学者效果差          |
| Python 版 Whisper / Coqui                    | 要在用户电脑上装 Python 环境，打包困难                                        |
| **sherpa-onnx（Node 原生模块）**             | 一个库同时支持 Kokoro、Piper、Whisper、VAD，提供 Windows 预编译版本，无需联网 |

## 决定

- 用 **sherpa-onnx-node 1.13.8**。
- **朗读**：Kokoro v0_19（英式女声 `bf_emma` 为主，对话里的其他角色用其他声音）。
  **只在开发时**预先生成全部课程音频（见 0004），所以 Kokoro 模型（约 330 MB）不打包进 app。
- **识别**：Whisper base.en 的 int8 版本（约 160 MB），打包进 app，在 Electron `utilityProcess` 里运行。
- 兜底：音频文件缺失时用 `speechSynthesis`；没有识别模型时切换到"自己评分"模式。

## 原因

- 本机实测：Kokoro 生成 4.3 秒的语音用了 1.8 秒；Whisper base.en int8 识别同一段只要 0.4 秒，而且完全正确。
- Whisper 对带口音的英语比较宽容，base 版本在入门级 CPU 上也足够快。
- 选英式口音是因为新加坡英语更接近英式拼写和发音习惯。

## 后果

- 识别只能告诉我们"说出了哪些词"，不能给每个音打分。第一版的发音反馈是**词级别**的（漏读、读错哪个词 + 词库里的口型提示）。
  音素级评分（比如 wav2vec2 音素模型）是以后的升级方向。
- Whisper 在静音时可能"幻听"出文字，所以识别前要先检查音量。
- 原生模块必须 `asarUnpack`（见 `electron-builder.yml`）。
