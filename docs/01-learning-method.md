# 01 · 学习方法

> 一句话：**先学能用的整句 → 听原音跟着说 → 按遗忘规律复习 → 当天在生活中用一次。**

## 1. 学习者与目标

- 学习者：新加坡中文补习中心的前台兼老师；国内本科毕业，字母熟悉、拼音很熟，但只会说个别单词（典型"哑巴英语"）。
- 目标是**日常生活和前台工作能开口**，不是考试。

| 时间（每天约 25–30 分钟） | 能做到                                                 |
| ------------------------- | ------------------------------------------------------ |
| 第 2 周                   | 敢开口：会打招呼，听不懂会求助，能做前台基本接待       |
| 第 6 周（第 1 阶段完成）  | 前台常见对话 + 生活基本场景（点餐、交通、购物、看病）  |
| 第 13 周（本版内容结束）  | 能调课、处理家长投诉、和同事闲聊，开始讲"昨天发生的事" |
| 第 9–12 个月（后续版本）  | 能讲清楚一件事，日常交流比较自如                       |

时间是参考值。Cambridge 估计每个 CEFR 等级大约需要 180–200 小时的学习时间；她每天身处英语环境，实际进度可能更快。

## 2. 方法与依据（如实标注证据强弱）

| 方法                 | 在 app 里怎么做                                                                                            | 依据                                                                                                                                                                                                                                                       | 证据强度                                                             |
| -------------------- | ---------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **整句优先**         | 每课 8–10 个现成句子块（Can I have…? / Sorry, can you say again?），不先讲语法                             | Michael Lewis《The Lexical Approach》(1993)；2022 年一项 38 名成人 EFL 学习者的研究显示，词汇法组的口语表现优于对照组                                                                                                                                      | 中等（样本小，衡量的是"感知的"口语水平）                             |
| **只学高频词**       | 只教常用词 + 新加坡生活 / 前台工作词                                                                       | Paul Nation：最常用的约 2000 个词覆盖日常英语的 68%–83%（数字随统计方法而不同）                                                                                                                                                                            | 强                                                                   |
| **间隔重复复习**     | FSRS 算法按遗忘规律安排复习                                                                                | Cepeda 等 2006 年综合分析（184 篇文章、317 个实验）：分散复习明显优于集中复习；2009 年研究：间隔合适时，长期记忆最多提高 150%                                                                                                                              | 很强                                                                 |
| **影子跟读**         | 每句都要：听原音 → 跟读录音 → 和原音对比                                                                   | 印尼、日本多项研究显示语速和流利度提高                                                                                                                                                                                                                     | 中等偏弱（多数研究不到 35 人，部分没有对照组）；对降低开口焦虑有帮助 |
| **输入 + 输出**      | 先听懂，再跟读，最后自己说（看中文说英文、情景对话）                                                       | Krashen 输入假说 + Swain 输出假说（1985）；现在主流观点认为两者都需要                                                                                                                                                                                      | 主流共识                                                             |
| **针对中国人的难点** | 拼音做桥；只讲中文里没有的语法（he/she、过去时、复数）；专攻 th、v/w、l/r、长短音、词尾辅音                | 中英语音和语法的对比                                                                                                                                                                                                                                       | 经验性                                                               |
| **万用句型 + 场景**  | 每个单元 1 个句型（少数一问一答 2 个），配 10 个例句，**每个例句一个具体场景**；后面的单元反复用前面的句型 | 构式学习：同一个句型见到的不同填法越多，越能自己造新句子（N. Ellis 2002，[SSLA](https://doi.org/10.1017/S0272263102002024)）；在什么情境学的，在类似情境里最容易想起来（Tulving & Thomson 1973，[Psychological Review](https://doi.org/10.1037/h0020071)） | 中等（以描述性研究和实验室研究为主）                                 |
| **看场景自己说**     | 句型课最后、以及复习里：只给场景和中文，自己说出英文                                                       | 提取练习：自己从记忆里想出来，比反复看记得牢得多（Karpicke & Roediger 2008，[Science](https://doi.org/10.1126/science.1152408)）                                                                                                                           | 强                                                                   |
| **先演一遍再上场**   | 每课的情景对话里要用到本单元句型；"不敢说"先在 app 里练                                                    | 重复同一个任务能提高流利度（Bygate 2001，_Researching Pedagogic Tasks_ 第 2 章）；外语焦虑是影响开口的真实因素（Horwitz, Horwitz & Cope 1986，[Modern Language Journal](https://doi.org/10.1111/j.1540-4781.1986.tb05256.x)）                              | 中等（"练过能减少紧张"属于经验性推断）                               |
| **当天实战**         | 每课一个"今日实战任务"                                                                                     | 学了马上用，记得牢，也有成就感                                                                                                                                                                                                                             | 经验性                                                               |

### 关于中文谐音

谐音能帮她**第一天就敢开口**，但用不好会让错误发音固化下来。所以规定：

- 分三级：🟢 很接近，直接给；🟡 近似，谐音 + 提示；🔴 中文里没有的音（如 th），**不给谐音**，只给口型说明。
- 界面上只显示拼音式谐音（如 `wò(t)`），不显示汉字（2026-10-24 用户反馈：汉字反而干扰）。汉字谐音保留在内容文件里，作为编写参考。
- 用拼音标注细节，例如 cup → kǎ(p)，括号表示只做口型、不出声。
- 一个词说对 3 次后（`HINT_FADE_AFTER = 3`），它的谐音自动隐藏；设置里有总开关。
- 永远先播原音。谐音由人逐条编写和检查，不让程序自动生成。

### 关于拼读

拼读的研究证据主要来自**儿童学阅读**，对成人学口语的直接证据少，所以只做"轻量版"：从第 2 周开始，每个单元的"句型课"那天最后约 3 分钟，一共 24 个小单元（`content/phonics/p01–p24`）。

## 3. 每天的流程

```
复习（到期的卡片，有上限）→ 今天的新内容（一个课程部分）→ 今日实战任务
```

每个场景分 3 天学，每周 2 个场景，第 7 天是复习日：

| 天  | 部分               | 内容                                           |
| --- | ------------------ | ---------------------------------------------- |
| 1   | 学新句子（learn）  | 听句子块、看中文和谐音、逐句跟读录音           |
| 2   | 句型课（practice） | 万用句型 + 10 个场景例句 → 看场景自己说 → 拼读 |
| 3   | 实战对话（apply）  | 情景分支对话 + 今日实战任务                    |
| 7   | 复习日（review）   | 本周对话再走一遍 + 复习                        |

## 4. 复习规则（`src/shared/domain/srs.ts`、`exercise.ts`）

- FSRS 参数：目标记忆保持率 90%，最长间隔 180 天，只按天安排（同一天内的重复在课程里完成）。
- 新学的内容在课程结束时算作一次"有点难"的接触，所以**第二天**就会出现第一次复习。
- 题型：一张卡片复习不到 2 次（`PRODUCTION_AFTER_REPS = 2`）时做"听英文选意思"（容易，建立信心）；之后改成"看中文说英文"（真正练口语）。语音识别不可用时，改成"想一想再自己评分"。拼读卡片做"听音选词"。
- 评分只有 3 档：😊 会了 / 🤔 有点难 / 😅 忘了。说英文的题由 app 自动判断：第一次就说对、没看提示 → 会了；重试或看了提示才说对 → 有点难；没说对或放弃 → 忘了。
- 语音比对：说对的词占比达到 80%（`PASS_SCORE = 0.8`）算通过；接近的词算半个，多说的词扣一点分。

## 5. 自动调速（`src/shared/domain/planner.ts`）

| 条件                                                | 模式                | 效果                                   |
| --------------------------------------------------- | ------------------- | -------------------------------------- |
| 到期复习数 > 每天上限 × 2                           | consolidate（巩固） | 建议今天只复习；她仍然可以选择学新内容 |
| 最近 7 天复习少于 15 次（`MIN_REVIEWS_FOR_PACING`） | normal              | 数据太少，不调速                       |
| 正确率 < 70%（`SLOW_ACCURACY`）                     | consolidate（巩固） | 同上                                   |
| 正确率 > 85%（`FAST_ACCURACY`）且到期数不超过上限   | fast（加快）        | 每天推荐 2 个新部分                    |
| 其他                                                | normal              | 每天推荐 1 个新部分                    |

- 每天复习上限默认 20 张（设置里可调 5–60）。超出的卡片留到以后几天，**界面上从不显示"欠了多少张"**。
- 隔了 3 天或更久（`WELCOME_BACK_AFTER_DAYS = 3`）再回来：当天复习上限降到 10 张，先让她轻松完成一次。

## 6. 防放弃设计（`src/shared/domain/streak.ts`）

| 设计                   | 规则                                                                                                                          |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 主数字是"累计学习天数" | 只增不减                                                                                                                      |
| 连续天数有"休息卡"     | 一开始有 1 张；每连续学满 7 天（`REST_CARD_EVERY`）得 1 张，最多 2 张（`MAX_REST_CARDS`）。漏学一天自动用掉一张，连续天数不断 |
| 门槛很低               | 学满 5 分钟（`MIN_ACTIVE_MS`），或者完成了当天的任务，就算学习日                                                              |
| 反馈先夸再改           | 每次只给一句鼓励 + 最多一个改进点，不显示冷冰冰的分数                                                                         |
| 看得见进步             | 第 1 天、第 6 周、第 13 周各录一段话（挑战 ch01–ch03），可以放在一起对比                                                      |

依据：Lally 等 2009 年伦敦大学学院的研究（96 人）发现，养成习惯平均要 66 天（18–254 天不等）；**漏一天对习惯养成影响很小**，但连续断一周影响明显。B.J. Fogg 的微习惯理论：习惯越小越容易坚持。注意：这些研究不是专门针对语言学习的，用在这里属于合理推断。
