# iPhone 主屏幕界面规范

日期：2026-10-29。设计目标为 iPhone 14 Plus 竖屏主屏幕应用（428 × 926 CSS pt），真实安全区以系统环境变量为准，不写死刘海或 Home indicator 高度。沿用原课程、句型、日常词、小故事与复习规则。

## 外壳

- viewport 使用 `width=device-width, initial-scale=1, viewport-fit=cover`。不设置 maximum-scale/user-scalable 禁用辅助缩放；按钮 `touch-action: manipulation` 避免双击缩放，保留需要的双指缩放。
- app 高度 `100dvh`，兼容回退 `100vh`；body 不滚动，shell `overflow: hidden; overscroll-behavior: none`，只有 main 独立纵向滚动，`min-height: 0`。不把所有元素锁定触摸而阻止内容滚动。
- 顶部标题栏加 `env(safe-area-inset-top)`；横向留至少 16 px，并加左右安全区。标题 24 px，英文学习句 26–30 px，正文 18 px，辅助说明至少 16 px，行高约 1.5。输入至少 16 px。
- 底部四标签：**今天 / 课程 / 复习 / 我的**，每个按钮至少 44 × 44 px，图标加文字、选中状态不只靠颜色。我的页放进度、速查、设置入口；今天也提供速查快捷入口。
- 标签栏包含底部安全区；学习步骤时隐藏标签栏，以免误触，只保留返回和底部主要动作。普通页固定主要动作时位于标签栏上方；步骤页下一步固定在 Home indicator 上方。main 必须预留整块操作区空间，最后一行内容不能被遮住。
- 子页顶部明确返回来源页；顶层今天/课程/复习/我的不显示返回按钮，通过底部标签切换。独立模式不依赖 Safari 返回；路由来源栈保留单元/周汇总的来源，退出录音时先停止麦克风。
- 只使用点击、长列表滚动和简单展开，不依赖 hover、拖拽或复杂动画。所有小图标按钮补足触摸区、accessible name 和可见焦点。
- portrait 写入 Web App Manifest，横屏仍可滚动操作，不声称系统一定锁定方向。随键盘/VisualViewport 调整固定操作区，不盖住输入或提交按钮。

## 播放、录音与反馈

首次进入句子显示“点一下听原音”，不假设页面加载就能自动播放。用户开始播放后可以连续播放，若系统阻止则显示继续播放按钮。原音始终先于跟读；缺少音频显示“这段音频还没下载”，提供连网重试和返回可用课程，不播放在线 TTS。

录音按钮至少 52 px 高，开始后原位变停止，显示音量和录音状态。麦克风权限提示说明“只在本机处理”，每次启动再次询问也能继续；拒绝后说明到 Safari/系统设置恢复权限，并提供返回。没有录音能力时可听原音、看答案，不能伪造自己的录音。

识别不是必须步骤。模型未下载显示“先录音，听听自己说的”，提供“听原音 / 听我的 / 原音和我的”，然后“说出来了 / 再练一次”。识别失败或超过时限也进入同一界面，保留刚才录音。反馈一次只给一句鼓励和一个可改进点，自评不显示机器分数。

## 首次使用与离线设置

首次页面说明添加主屏幕的方法，不依赖 iOS 不支持的安装弹窗。应用图标使用 `apple-touch-icon`、manifest 192/512 图标和 maskable 图标；状态栏 `apple-mobile-web-app-status-bar-style=default`，背景与顶部安全区一致。提供 Apple startup image（按设备 media 匹配）与应用内简单启动页，不能只给桌面 favicon。

初次下载显示“正在准备第 1 周”、已校验字节/总字节、暂停/继续；完备后显示“第 1 周可离线使用”。其他周继续下载，应用关闭后下次继续。设置显示每周是否可离线，不把所有课程标题可见误称音频全下载。

离线识别独立开关，下载前显示实际清单大小和“建议连接 Wi-Fi”；不阻挡先上课。下载失败可重试，删除模型不删除课程/学习记录。更新提示“有新版”，用户完成当前步骤后点“更新并重新打开”，录音和保存中禁用。

## 备份与错误

设置中提供“导出全部学习数据”和文件选择“导入备份”。导入先显示日期、录音数，明确会替换当前记录；确认前准备现有备份。无文件系统目录接口时使用 Blob 下载/可用的文件分享，并提示保存到“文件”。不要把已生成下载文件称为已经保存成功。

提示：“数据只保存在这台手机。删除主屏幕应用或清除网站数据可能丢失记录，请先导出备份。”空间不足时停止下载并提示处理空间；学习保存失败保持当前页和可重试操作，不能显示完成。

## 验收

用 Mock API 检查每个页面进入/返回、单元和周汇总来源、拒绝麦克风、识别回退、下载中断及备份入口；428 × 926 和更小宽度检查无横向溢出、无底部遮挡、点击区域与字体。真机检查主屏幕安全区、键盘、静音开关、录音后扬声器、杀进程离线重开和数据恢复；截图与未通过项写入 `docs/web/mobile-validation.md`。设计尺寸检查不能替代真实 iPhone 测试。
