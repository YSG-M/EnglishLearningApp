# iPhone 试用步骤与记录

发布完成后，用 Safari 打开 https://ysg-m.github.io/EnglishLearningApp/，点击“分享 → 添加到主屏幕”。以后从主屏幕图标进入；首次下载保持联网并停留前台。请先用测试记录试用，真机结果尚未填写。

## 按顺序试用

1. 保持联网、应用停留前台，等第 1 周显示“可离线使用”。试着暂停、继续下载，再进入第一课并播放原音。
2. 打开飞行模式，并确认 Wi-Fi 也已关闭。退出并从应用切换器划掉应用，再从主屏幕图标打开。打开第 1 周课程、播放原音、完成学习，重开后核对记录还在。
3. 开启手机侧面的静音开关，测试原音、慢速和连续播放。记录是否能从扬声器听到。
4. 点击录音并允许麦克风，说一句话后停止。核对麦克风指示灯消失；回听自己的声音，再播放原音，比较录音前后的音量与扬声器位置。录音中返回、锁屏、切后台后，也应能重新录音。
5. 关闭应用后重开，再录一次，记录是否重新询问麦克风权限。也试一次拒绝权限后的恢复。
6. 联网时在“我的 → 设置”单独启用并下载离线识别。完成后重新断网，录三句短句。分别记录第一次等待和随后每句从停止录音到出现结果的秒数、识别文字、是否卡住或退出。失败时应能回听并自己评分。细节见 [语音说明](speech.md#iphone-人工验收待用户执行)。
7. 在“我的 → 设置”导出全部学习数据，再点击下载/分享，亲自保存到手机“文件”。记录当前进度和设置；修改一项设置后选择刚保存的备份，核对日期和录音数。先准备并保存当前数据备份，再确认替换。重开后检查原来的设置、进度和录音都恢复。详见 [存储与恢复](storage.md#完整备份)。
8. 检查今天、课程、复习、我的、设置和汇总；进入一课滚到底，确认“下一步”可点。转横屏、打开速查键盘、收起键盘，核对输入框、按钮、刘海及底部横条没有挡住内容。

数据只在这台手机。测试期间也不要清除网站数据或卸载应用；保存到“文件”的完整备份是恢复依据。电脑测试不能替手机填写结果。

## 对手机的影响 / 如何彻底删除

课程音频、可选识别模型、学习记录和录音会占用手机空间；识别时会使用处理器与内存。首次下载和更新需要网络，完整下载的课程可离线使用。麦克风在录音时申请使用，学习数据不上传。重要记录请定期导出到“文件”。

彻底删除前先导出需要保留的备份，再删除主屏幕应用。在“设置 → App → Safari → 高级 → 网站数据”搜索 `ysg-m.github.io` 并删除数据（旧版 iOS 可能在“设置 → Safari”）。这会清除网站的本地记录、录音和下载缓存，也可能影响同域其他页面。保存在“文件”的备份需另行删除。
