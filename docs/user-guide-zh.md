# 开口说 · 使用说明

你好！这个软件是专门为你做的。不用联网，不用花钱，每天 20–30 分钟就够了。

**最重要的一句话：说错没关系，能开口就是进步。** 🌱

---

## 每天怎么学

打开软件，首页会告诉你今天要做什么，跟着点就行：

1. **复习** 🔁 —— 把之前学过的句子再练一遍（最多 20 张，几分钟就完成）
2. **今天的新内容** 📘 —— 每天一小节
3. **今日实战任务** 🎯 —— 在生活里用一次，比如上班时对家长说一句 Good morning!

太累的时候，**只做复习也算完成今天**。学满 5 分钟，今天就算一个学习日。

每个场景分 3 天学：

- 第 1 天：学新句子，跟着读
- 第 2 天：换词练习 + 拼读小课（3 分钟）
- 第 3 天：模拟对话 + 实战任务

每周第 7 天是复习日，轻松一点。

## 按钮说明

| 按钮 | 作用                                     |
| ---- | ---------------------------------------- |
| ▶    | 听原音                                   |
| 🐢   | 慢速听                                   |
| 🎤   | 开始说话。说完停一下，软件会自动停止录音 |
| ▶▶   | 先播原音，再播你的录音，对比一下         |
| 💡   | 提示：先给第一个词，再给谐音，最后给答案 |

## 句子下面的小字（谐音）

- 🟢 绿色：照着读就很接近
- 🟡 黄色：大致这样读，**注意旁边的小提示**（比如"结尾 t 轻轻收住"）
- 🔴 红色：中文里没有这个音，不给谐音。点一下看口型说明，多听原音

一个词你说对 3 次后，它的谐音会自动藏起来，说明你已经会了 👏。想一直看的话，可以在设置里打开。

**一定要先听原音再看谐音**，谐音只是帮你起步的拐杖。

## 软件没听清怎么办

- 离麦克风近一点，周围安静一点，说完停一下
- 一个词一个词慢慢说也可以
- 实在识别不出来，没关系：点"我说对了"或者"显示答案"继续往下学。**识别不准不是你的错**，电脑听带口音的英语本来就不太准
- 如果软件提示"语音识别不可用"，就改成自己判断：心里说一遍，点开答案对照，然后选 😊 会了 / 🤔 有点难 / 😅 忘了

## 漏了一天？没关系！

- 你有**休息卡** 🛌：漏学一天会自动用掉一张，连续天数不会断。每连续学满 7 天送一张，最多存 2 张
- 首页最大的数字是**累计学习天数**，它只会增加，不会减少
- 隔了几天再回来，第一天的复习会自动变少，轻松接上
- 复习多了也不用担心：每天最多 20 张，剩下的会自动分到后面几天

研究发现，养成一个习惯平均要两个多月，偶尔漏一天几乎没有影响。重要的是**回来继续学**。

## 看看自己的进步

- 第一次打开时，录一段自我介绍（只说几个词也可以）
- 第 6 周和第 13 周各再录一次
- 在"我的进步"页面，可以把三段录音放在一起听 —— 你会惊讶的 😊

## 遇到问题

在"设置"里点 **导出诊断包**，会在桌面生成一个文件夹，发给你老公就行。你的学习记录都保存在这台电脑上，不会上传到任何地方。

加油！每天开口说几句，三个月后你会感谢现在的自己。💪
